# 05 · 瑞士国际主义风格设计规范

> 2026-11 重构。所有取值集中在 `css/app.css` 顶部的 `:root` 与两套主题块里，
> 改风格只动令牌，组件层禁止出现新的魔法值。

## 1. 设计令牌

### 字体与字阶

| 令牌 | 取值 | 复用规则 |
| --- | --- | --- |
| `--font-ui` | Inter / HarmonyOS Sans SC / PingFang SC / Microsoft YaHei / system-ui | 全局唯一字体，含标题、按钮、数字 |
| `--font-serif` | 兼容别名，已指向 `--font-ui` | 旧代码引用不必清理，但新代码禁用 |
| `--fw-body` | 300（极细） | 正文、标题默认字重 |
| `--fw-em` | 400 | 仅用于强调（`strong`、激活态、标签） |
| `--fs-xs` | 11px | 辅助信息、角标 |
| `--fs-sm` | 12px | 次要文本、按钮小字 |
| `--fs-md` | 13.5px | 正文默认字号（body） |
| `--fs-lg` | 16px | 小节标题 |
| `--fs-xl` | 24px | 页面标题 h1 |
| `--fs-2xl` | 28px | 统计大数字 |

规则：**层级只靠字号区分，禁止用加粗做层级**；全文只有 300/400 两档字重。

### 色板（冷灰低饱和 + 单一强调色）

| 令牌 | 浅色 | 深色 | 复用规则 |
| --- | --- | --- | --- |
| `--bg` | `#e9eaec` | `#141618` | 页面基底 |
| `--bg-2` | `#e2e4e6` | `#17191b` | 侧边栏 |
| `--surface` | `#f4f5f6` | `#1d2023` | 卡片 / 面板 / 对话框 |
| `--surface-2` | `#ebedef` | `#232629` | 内嵌底、输入底 |
| `--ink` | `#17191b` | `#e7e9eb` | 主文字、品牌块 |
| `--ink-2` | `#45484c` | `#b3b7bc` | 次级文字、进度填充 |
| `--muted` | `#7a7f85` | `#7e848a` | 弱化文字 |
| `--line` | `#cfd2d5` | `#2b2f33` | 一级分隔线 / 描边 |
| `--line-2` | `#dcdfE1` | `#232629` | 二级分隔线 |
| `--accent` | `#002fa7` 克莱因蓝 | `#5273ff`（提亮档） | **全局唯一强调色** |
| `--accent-ink` | `#ffffff` | `#ffffff` | 强调色上的文字 |
| `--accent-soft` | 8% / 16% alpha | 同左 | 选中淡底 |
| `--danger` | `#a2372b` | `#e07a6b` | 仅破坏性操作 |
| `--dot` | ink 9% | ink 7% | 点阵纹理色 |

**强调色白名单**（仅以下场景可用 `--accent`）：

1. 主按钮 `.btn.primary`、链接文字；
2. 选中 / 激活态：导航（左 2px 标线）、筛选 chip、卡片多选、合并勾选、目录当前项、`.btn.ghost.active`；
3. 焦点环（`:focus-visible`、表单聚焦描边）；
4. 拖选框、拖放虚线框、导入进行中指示点。

进度条、统计图形、角标、品牌块、图标一律中性灰阶（`--ink` / `--ink-2`）。

### 形态

| 令牌 | 取值 | 规则 |
| --- | --- | --- |
| `--r-sm/md/lg/xl` | 全部 `0px` | 卡片、按钮、输入、面板、对话框一律直角；不得新增圆角字面量（图片圆角同理） |
| `--shadow-1/2/3` | 全部 `none` | 不使用投影；层级靠 1px `--line` / `--line-2` 分隔线与描边表达 |
| 勾选框、滑块 thumb | 直角方块 | 与整体形态一致 |

### 基底与栅格

| 令牌 | 取值 | 说明 |
| --- | --- | --- |
| `--grid-unit` | 8px | 间距取其整数倍（8/16/24/32） |
| `--dot-size` | 1px | 点阵半径 |
| `--dot-gap` | 22px | 点阵间距 |

点阵纹理只铺在 `body` 一层：`radial-gradient(var(--dot) 1px, transparent 1px)`，
不随内容滚动；侧栏、卡片等实底元素自然遮挡。`html[data-perf="low"]` 下自动关闭。

## 2. 组件语言

- **卡片化**：书架卡、统计卡、面板、对话框统一为「`--surface` 实底 + 1px `--line` 描边 + 直角」。
- **反馈**：不做悬浮位移/投影，hover 改为描边加深（`.card-cover` 边框 → `--ink-2`）。
- **选中态统一语义**：`2px 强调色外框`（卡片选中）或 `2px 左标线`（导航激活）或「强调色文字 + 淡底」（chip / 按钮）。
- **阅读器**：默认主题换成冷灰纸面（`#f4f5f6`）；sepia/dark/black 是用户可选的阅读模式，保留功能色。EPUB 默认字体随全局切到无衬线，用户仍可在阅读设置里改 serif/kai。
- **封面占位图**：由随机色相改为冷灰阶（哈希只决定明度 20–33%），字体无衬线。

## 3. 响应式

令牌在所有断点（1180 / 900 / 640 / 矮屏 700px）下不换值，仅栅格列数与间距缩放，
因此风格在任何宽度下一致。触屏目标尺寸（44px 等）沿用 `tablet.css` 原规则。

## 4. 涉及文件

- `css/app.css`：令牌重写 + 全组件直角化/去投影/去衬线
- `css/reader.css`：阅读界面冷灰化、控件直角、进度滑块方帧、EPUB 排版无衬线
- `css/tablet.css`：backdrop 冷色化、低端机关点阵
- `index.html` / `manifest.webmanifest`：theme-color 同步
- `assets/icon.svg`：直角 + 克莱因蓝
- `js/util.js`：`fallbackCover` 冷灰阶占位
