# 一册 · 桌面/平板版：功能模块与交互流程

> 参考对象：<https://tomereader.cc/>（「一册」，本地私密漫画与小说阅读器）。
> 本实现是一个**纯本地、无后端**的桌面/平板版复刻，数据全部留在浏览器 IndexedDB 中，不上传任何服务器。

---

## 1. 对参考站的理解

从站点前端可确认的信息：

| 维度 | 参考站的做法 |
| --- | --- |
| 定位 | 本地 · 私密 · 漫画与小说阅读器，支持 cbz / epub |
| 结构 | 单页应用，路由 `/`、`/reader/:id`、`/tutorial`、`/terms`、`/privacy`，另有 `/en/*` |
| 存储 | 浏览器本地库（localforage），按 `${id}-file`、`${id}-file-${n}` 分片存放原始文件 |
| 书架 | 空状态引导导入 → 封面网格（3:4）+ 进度条 + 类型 + 新书标记 → 右键菜单 |
| 阅读 | 顶部返回/书名/目录/阅读设置/全屏，底部进度条；目录与设置都是抽屉面板 |
| 其他 | 暗色模式、语言切换、存储占用提示、书籍数量上限、容量不足提示 |

本实现按上述骨架落地，并补齐了桌面端更常用的键鼠交互、搜索排序、书籍详情与统计。

## 2. 模块划分

```
┌──────────────────────────────────────────────────────────┐
│ 外壳：侧边导航 / 顶栏（标题 + 搜索 + 排序 + 导入）       │
├──────────────────────────────────────────────────────────┤
│ 书架视图 │ 最近阅读 │ 阅读概览 │ 设置                     │
├──────────────────────────────────────────────────────────┤
│ 导入管线（解析 → 封面 → 落库 → 渲染）                    │
├──────────────────────────────────────────────────────────┤
│ 阅读器外壳（工具条 / 目录 / 设置 / 进度 / 快捷键）        │
│   ├─ EPUB·TXT 引擎：CSS 多栏分页                         │
│   ├─ CBZ 引擎：单页 / 双页 / 条漫 + 缩放                 │
│   └─ PDF：交给浏览器内置查看器                           │
├──────────────────────────────────────────────────────────┤
│ 数据层：IndexedDB（books / files / prefs）               │
└──────────────────────────────────────────────────────────┘
```

### 2.1 书架

- 封面网格，`auto-fill minmax(160px, 1fr)`，封面 3:4，底部 3px 进度条。
- 角标：`新`（导入后未读）、类型（漫画/小说/文本/PDF）。
- 检索：书名、作者；排序：最近阅读 / 导入时间 / 书名 / 阅读进度。
- 筛选：全部 / 漫画 / 小说 / 在读 / 读完。
- 右键（或卡片右上角 `···`）：选择（多选合并）、开始/继续阅读、书籍详情、标记为未读、合并到另一本、删除。
- **多选**：`Ctrl/Cmd + 点击` 逐本切换、`Shift + 点击` 范围选择、`Ctrl + A` 全选当前筛选结果、**按住拖动划过卡片连续选中**；有选中项后单击卡片变为「切换选中」，双击才打开书。底部浮出操作条，显示已选本数与章节数、类型校验结果，并提供全选 / 合并为一本 / 取消；顶栏在多选时另有一个常驻「全选 / 取消全选」。
- 详情弹窗：封面、作者、类型、体量、文件大小、格式、导入时间、最近阅读、进度与三个动作；多分段的书额外列出**章节清单**（第 N 章 · 分段名 · 页数）。
- 空状态：拖拽说明 + 「开始导入」按钮；筛选无结果时给单独的提示文案。

### 2.2 导入

支持 `.epub` / `.cbz` / `.txt` / `.md` / `.pdf`（`.cbr` 会给出「RAR 暂不支持」的明确提示）。

流程：多选或拖放 → 逐个解析成「分段」→ 按文件名归组 → 提取封面 → 检查重复与容量 → 写入 IndexedDB → 增量刷新书架。

**多分段归并（一本书 = 多个文件）**

- 文件名里带卷/章编号时（`第01卷` `第十二章` `ch03` `vol.2` `[01]` `夜航 - 05` `三体2` `上册/中册/下册`），会先剥掉编号得到「主干」，同类型且主干相同的文件并入同一本书，按编号排序。
- 同一批里选多个文件、或分多次导入，都能归到同一本：已有书目按 `series.key` 匹配，新分段插入到序号对应的位置。
- 没有编号的文件（如 `孤岛.cbz`）仍是一文件一本书，不会被误合并；4 位年份（`夜航（2019）`）不当作卷号。
- 书名取主干（`夜航 01.cbz` → 《夜航》），封面若是程序生成的占位图，会按最终书名重画。
- 右键「合并到另一本」可手动把一本书的所有分段并入同类型的另一本，用于文件名对不上、自动识别失败的情况。

**多选合并（2 本以上）**

自动归并认不出主干的散装文件，靠手动多选合并：

1. 选中若干同类型书籍 → 底部操作条「合并为一本」；
2. 弹窗逐行列出这些书（封面、分段数、已读进度），用单选决定**保留哪本的书名、封面与进度**；默认按「分段数最多 → 进度最高」预选；
3. 所有分段合并后交给全局 `sortParts` 排序，跨书卷号能交错对齐（第一册在 A 本、第二册在 B 本，合并后仍 1 → 2）；
4. 其余书目记录删除，`files` store 里的 Blob 按分段 id 保留，不重复占空间；
5. 混选不同类型或含 PDF 时合并按钮禁用，操作条直接给出原因；
6. 合并完成后弹出**结果面板**：不再只报总页数，而是按章节逐条列出「第 N 章 · 文件名 · 页数」，本次新并入的章节高亮并标注「新并入」，可直接「开始阅读」。

右键「合并到另一本」在已多选的情况下会把这批全部并入目标，效果等同于上一步换个入口。

- **EPUB**：解析 `container.xml → OPF`，取标题/作者/章节数，封面优先 `meta[name=cover]`，其次 `properties="cover-image"`，再退化为文件名匹配。
- **CBZ**：读取 ZIP 内图片，按文件名自然排序（`page2 < page10`），首页当封面，过滤 `__MACOSX`、隐藏文件与 `thumb/` 目录。
- **TXT**：按「第 N 章 / Chapter N / 1、」等标题行切章，无章节时视为单章。
- 封面统一压到 520px 宽的 JPEG 再入库，避免把几 MB 原图塞进元数据；无封面时生成**纯文字封面**（非图片占位）。
- 失败原因逐条显示：已在书架中 / 格式不支持 / 压缩包损坏 / 存储空间不足 / 超过 400MB。
- 导入面板固定在右下角，显示 `n / total` 与每本状态，完成后自动收起。

### 2.3 阅读器（EPUB / TXT）

- **分页方式**：内容注入 `.epub-flow`，用 `column-width = 可视宽度` + 固定高度做多栏，`translateX` 翻页。
- **章节切换**：到底自动进入下一章，回退则落在上一章末页。
- **目录**：优先 EPUB3 `nav[epub:type=toc]`，退化到 NCX；带锚点的条目会先定位到元素再换算成页码。
- **设置**：字号 14–32、行距三档、字体（宋体/黑体/楷体）、背景四套（纸白/米黄/深色/纯黑）、版心宽度三档。
- **进度**：`(章索引 + 页内比例) / 总章数`，底部滑杆可跨章跳转，进度 600ms 防抖落库。
- **样式隔离**：剥离书内 `<style>/<link>/<script>` 与内联事件，图片转 `objectURL`，内部链接转成章节跳转，保证主题与排版不被书籍 CSS 破坏。
- **裁剪**：分栏内容会在 `padding` 区域溢出，因此单独加了一层 `.epub-clip` 做裁剪（早期版本会在正文左侧露出上一栏的残字，已修复）。

### 2.4 阅读器（CBZ）

- 三种模式：单页、双页对开、纵向条漫。
- 双页支持从右到左（日漫），页序按 RTL 反转渲染。
- 画面适应：适高 / 适宽 / 原始尺寸。
- 缩放：`Ctrl + 滚轮` 或双指捏合，放大后可拖拽平移；未放大时滚轮直接翻页。
- 条漫：`IntersectionObserver` 懒加载，先用首页比例给所有页预留高度，再恢复滚动位置，避免"图片没加载 → 位置跳到最上面"。
- 图片按页缓存，超出当前页 ±3（分页）/ ±10（条漫）即释放 `objectURL`，控制大体积漫画的内存。
- 多分段（合并过的）漫画：目录按**章**列出，每章标出页码范围，一点跳到该章第一页；底部进度标签带上当前章名（`第 2 章 · 13 / 40 页`）。

### 2.5 多选与合并

| 状态 | 点击卡片 | 双击卡片 |
| --- | --- | --- |
| 无选中 | 打开书 | 打开书 |
| 已有选中 | 切换该本选中 | 打开并退出多选 |

- 入口有两个：顶栏「多选」按钮（触屏 / 平板这类没有 Ctrl 键的场景），或 `Ctrl` 点击 / 右键「选择」直接进；顶栏按钮会保持高亮，直到取消。
- 选中态：左上角勾选圈（多选模式下未选中的卡片显示空心圈，提示可点）、橙色描边、标题变橙；多选时隐藏「新」角标与 `···` 按钮，避免抢注意力。
- 操作条固定底部居中，`pointer-events` 只落在条内，不影响滚动与点卡片；底栏出现时书架底部留 76px、toast 上移到 92px。
- 选择集合以书目 id 保存，删除/合并掉的书会被 `pruneSelection` 自动剔除；切换视图、按 `Esc` 都会清空。
- 筛选不会清空已选（只在筛选结果内计算「全选」状态），避免选完再筛就丢。

**拖动 / 滑动连选**

| 手势 | 行为 |
| --- | --- |
| 卡片上按下并划过多张 | 按书架顺序把起点到当前卡片整段选中（起点已选中则整段取消） |
| 空白处按下并拖出选框（鼠标） | 拉框，框到的卡片一起选中 |
| 触屏横向滑过卡片 | 进入连选并接管手势；纵向滑仍然滚书架 |
| 拖到列表上下边缘 | 自动滚屏，继续扩展选择 |
| 顶栏「全选」/ 底栏「全选」 | 切换当前筛选结果的全选状态 |

- 只在多选状态下接管拖拽，未进入多选时拖动卡片不会误选，原有点击 / 双击 / 键盘逻辑不变。
- 选中状态用 `requestAnimationFrame` 合帧刷新，拖动过程里勾选圈和计数实时变化。
- 拖选松手后 400ms 内忽略浏览器补发的 `click`，避免刚划好的一段被翻转。

### 2.6 设置与数据

- 界面主题：浅色 / 深色 / 跟随系统。
- 阅读默认值：正文字号、漫画默认模式（只影响新打开的书，单本调整会写入 `book.rprefs` 覆盖默认值）。
- 存储：`navigator.storage.estimate()` 显示已用/配额，可一键清空（保留外观偏好）。
- 阅读概览：藏书、在读、读完、文件体积、类型分布。

## 3. 交互流程

### 3.1 首次使用

```
空书架 → 点击「开始导入」/ 拖入文件 → 解析中（面板逐条反馈）
        → 成功：卡片出现在书架，带「新」角标
        → 失败：条目变红并给出原因，其余文件继续
```

### 3.2 多选合并

点顶栏「多选」（或右键 →「选择」/ 按住 `Ctrl` 逐本点）→ 底部操作条显示 `N 本已选 · M 个文件 → 1 本`
→「合并为一本」→ 在弹窗里点选保留哪本的书名与进度 →「合并为 1 本」
→ 书架刷新为一条书目，体量显示 `总页数 · N 个文件`，打开后可以跨文件连续翻页。

### 3.3 打开与续读

```
点击卡片 → 读取 books 记录 + files Blob → 选择引擎（EPUB/TXT/CBZ/PDF）
        → 按 book.loc 恢复章节与页码 → 顶部/底部工具条 3.2s 后自动隐藏
        → 翻页：更新进度 → 600ms 防抖写回 → 关闭时立即落库
```

### 3.4 阅读器内的操作

| 操作 | 鼠标 / 触摸 | 键盘 |
| --- | --- | --- |
| 上一页 / 下一页 | 点击左右 26% 区域 | `←` `→` `PageUp` `PageDown` `空格` |
| 显示/隐藏工具条 | 点击中间区域 | — |
| 目录 | 顶部「目录」 | `T` |
| 阅读设置 | 顶部「阅读设置」 | — |
| 全屏 | 顶部全屏按钮 | `F` |
| 退出阅读 | 顶部返回 | `Esc`（面板打开时先关面板） |
| 调整字号（EPUB） | `Ctrl + 滚轮` | — |
| 缩放（漫画） | `Ctrl + 滚轮` / 双指 | — |

夜间/米黄主题、单双页、RTL 等设置会即时生效并写回当前书籍。

## 4. 数据模型

```js
// books（keyPath: id）
{
  id, title, author, type: 'epub' | 'comic' | 'txt' | 'pdf', ext,
  cover,          // dataURL（压缩后的封面）
  size, addedAt, lastReadAt,
  progress: 0..1,
  finished: boolean,
  isNew: boolean,
  count, countLabel,          // 全书章节数 / 页数（各分段求和）
  parts: [                    // 分段：一本书可以由多个文件组成
    { id, name, size, ext, type, count, countLabel, order: [卷号, 章号] }
  ],
  series: { key, base },      // 系列名，用于后续导入自动归并
  loc: { chapter, page, ratio, mode },  // 断点（按全书连续编号）
  rprefs: { ... }             // 单本阅读设置覆盖值
}
// 早期数据没有 parts 字段：bookParts() 会退化成 [{ id: book.id, ... }]

// files（keyPath: id）   { id, file: Blob, size, type }   // id 是「分段 id」
// prefs（keyPath: k）    { k: 'prefs', v: { theme, epub, comic } }
```

设计取舍：
- **一本书 = 多个分段**。分段是最小单位，一本书的章节索引是各分段章节的连续拼接；阅读器按 `{ 册号, 册内序号 }` 定位，所以跨卷翻页、目录跳转、进度记录都是连续的。
- **原始文件整包存**，阅读时重新解析。好处是逻辑简单、进度与书籍不脱节；代价是每次打开 EPUB 要重新解包（本地 Blob，通常 <300ms）。
- **封面单独压图存 metadata**，列表渲染不需要碰原始文件。
- **进度存在书上**，不单独建会话表（参考站有更细的阅读统计，本版只做"读到哪"）。

## 5. 与参考站的差异

| 项 | 说明 |
| --- | --- |
| 多语言 | 未做中英切换，界面为中文 |
| 教程/条款/隐私 | 未做独立页面，使用说明并入「设置」 |
| PDF | 能导入、能用浏览器内置查看器阅读，但不记录页码进度；Android 上需换 pdf.js |
| CBR | 明确提示不支持（RAR 解压需要额外库） |
| 阅读统计 | 只做书库概览，没有按天热力图/阅读时长（那是自托管版 Tome 的能力） |
| 导入上限 | 单本 400MB、最多 500 本，超出会给出提示 |
